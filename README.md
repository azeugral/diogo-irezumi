# Diogo Irezumi — prévia

Site de Diogo Teixeira (@diogo_irezumi), tatuagem japonesa na Black Tiger Tattoo Shop, Loures. PT-PT, `noindex`.

**Direção:** kakejiku (pergaminho pendurado). No hero, os flashes do Diogo desenrolam-se num pergaminho ao centro, sobre laca negra, com o nome dividido dos dois lados. Paleta laca `#14100e`, papel `#eee6d5`, vermelhão `#c2301f`. Zen Old Mincho + IBM Plex Sans. Marca: torii em vetor (o ⛩️ que ele usa na bio).

- `index.html`, `assets/css/site.css`, `assets/js/site.js` (pergaminho em WAAPI, grades, lightbox, formulário que copia a mensagem e abre `ig.me/m/diogo_irezumi`).
- `assets/js/dados.js` gerado; imagens em `assets/img/*` por `tools/preparar.py` a partir de `../_ref/ig` (177 posts).
- `tools/auditar.py` (12 larguras), `tools/testar.py` (interações), `tools/fotos.py` (página inteira).
